# Анализ сложности функции PasswordGeneratorService.Generate

## Оценка сложности: O(n), где n — длина генерируемого пароля

## Обоснование

Функция `Generate` выполняет линейное количество операций относительно длины пароля. Ниже приведён пошаговый разбор:

| Шаг | Код | Сложность | Описание |
|-----|-----|-----------|----------|
| 1 | Валидация длины (строка 25) | O(1) | Одно сравнение `options.Length < 4` |
| 2 | `BuildCharset` (строка 28) | O(1) | Формирование набора символов из фиксированного числа констант (максимум 4 набора по ~26 символов каждый) |
| 3 | Выделение массива (строка 29) | O(n) | Создание массива `char[n]` |
| 4 | `GetRequiredChars` (строка 31) | O(1) | Вызов `BuildCharset` (O(1)) + не более 4 вызовов `Random.Next` |
| 5 | Заполнение обязательных символов (строки 32–35) | O(1) | Цикл выполняется не более 4 раз (по числу включённых наборов) |
| 6 | Заполнение случайными символами (строки 37–41) | O(n) | Цикл выполняется `n - k` раз, где k ≤ 4 — количество обязательных символов |
| 7 | `Shuffle` (строка 43) | O(n) | Алгоритм Фишера-Йейтса: один проход по массиву длины n |
| 8 | Создание строки (строка 45) | O(n) | Конвертация массива `char[]` в `string` |

**Итого: O(n)**

## Примечания

- Константа 4 (число наборов символов) не зависит от входных данных, поэтому все операции с фиксированным числом итераций относятся к O(1).
- Нет вложенных циклов, рекурсии или операций с асимптотикой выше линейной.
- `BuildCharset` всегда обрабатывает не более 4 строк фиксированной длины, поэтому её сложность O(1).
